## Unmodified baseline verification

The generated .NET solution restored and built using SDK 10.0.403 (compatible with its `10.0.201` / `latestFeature` global.json). The default restore is blocked by current NuGet security advisories promoted to errors by the template. For this isolated historical baseline only, restore/build used `-p:WarningsNotAsErrors=NU1902%3BNU1903`; auditing remains enabled and the build reports 126 warnings, zero errors. This exception must not be carried into the active application. No generated source or package versions were patched to claim an unmodified build.

Local official Domain unit tests: 6 passed; Application unit tests: 8 passed. The Infrastructure integration project contains no test cases. The full test command was actually attempted: the 19 functional cases failed in the Aspire PostgreSQL health setup before assertions, and the six browser cases failed because the pinned Playwright Chromium binary was absent. These are recorded as environmental failures, not passing or silently skipped tests. The separate baseline CI runs the same original test projects with Docker and Chromium.

The official React frontend uses Vite, React 19, Pico CSS, Lucide, and `nswag run /runtime:Net100`; NSwag reads the backend's generated `wwwroot/openapi/v1.json` and writes `src/web-api-client.ts`. A clean `npm ci --ignore-scripts` and original `npm run build` both passed, including NSwag generation. Generated client/build products are not part of the 171-file source baseline.

## Mechanism inventory

- `src/Domain`: template entity/event/value object conventions and Todo sample.
- `src/Application`: MediatR 14.1.0, handler scanning, Logging preprocessor; UnhandledException → Authorization → Validation → Performance behaviors; FluentValidation 12.1.1 and AutoMapper 16.1.1.
- `src/Infrastructure`: EF Core 10.0.5 with Npgsql 10.0.1; IdentityDbContext, Identity Core, roles, sign-in manager, token providers and IdentityService; audit/domain-event interceptors.
- `src/Web`: composition through the three Add*Services extensions; `IEndpointGroup` discovery, named handlers/OpenAPI operation IDs, current user from HttpContext, ASP.NET OpenAPI and Scalar.
- `src/Web/ClientApp`: actual React SPA and NSwag Fetch clients; template npm version ranges and `nswag: latest` remain unchanged here and will be pinned during migration.
- `src/AppHost`, `src/ServiceDefaults`, `src/Shared`: Aspire local orchestration and optional Azure resources. The generated Azure workflow is preserved but not invoked. Its push trigger is restricted to main/master; this review branch does not match it.
- `tests`: NUnit/Shouldly/Moq unit tests, functional tests through scoped ISender and WebApplicationFactory, Aspire test host/Respawn, and Playwright browser tests.

The template's development initializer deletes and recreates its sample database. It must never be used against existing EchoCase data. The business migration must preserve EchoCase's migration chain, identity rows, aggregate version, receipts, audit, and transaction boundary, and remove sample/deployment components from the active four-directory application.
