# 阅读路线与证据约定 {#preface}

这本书围绕一个可运行的应用展开：调查员登录 EchoCase，进入虚构案件“雾港档案”，查阅证据、建立关联、记录推理，最后提交由证据支持的结论。业务故事只是约束载体。真正要回答的是：当两个窗口同时修改调查时，谁的决定有效？网络中断后点击重试，会不会重复写入？隐藏按钮以后，别人的档案是否仍能被 API 读取？数据库已经提交而客户端没有收到响应时，什么才算完成？

读者应已熟悉一种后端语言、HTTP 和关系数据库。书中不展开语法入门，而是沿着同一调查工作流剖开框架机制，并把设计决定放回具体约束中评估。实现采用 .NET 10、ASP.NET Core、EF Core、PostgreSQL、React 19、TypeScript、TanStack Query 和 React Flow。这里的“企业工程”指可解释的约束、可审计的变更和可重复的验证，不表示系统已经承担过企业生产流量。

## 怎样使用这本书

推荐先运行应用，再从第 1 章逐步阅读。在领域和数据一致性章节，先预测实验结果，再执行命令，最后比较你的解释与参考答案。前端章节依赖已有的版本冲突与幂等语义；跳过后端协议直接写交互，通常会把正确性问题藏进缓存与按钮状态。

| 学习路径 | 重点章节 | 完成后应能解释 |
|---|---|---|
| 架构与领域 | 1–3、5 | 哪些规则属于聚合，什么条件值得增加抽象 |
| API 与一致性 | 4、6–10 | 请求穿过哪些边界，如何处理并发、重复和越权 |
| 全栈交互 | 11–13 | 本地草稿、服务端快照与图谱布局为什么分开 |
| 质量与运行 | 14–18 | 什么证据足以支持一个结论，什么仍然没有验证 |

所有章节共享一份源代码，而不是为每个框架建立一个孤立演示。书中短代码片段在构建时直接摘取当前仓库文件；行号由发布源标记指定，超出文件边界会使构建失败。原始命令输出、测试结果和测量样本留在 `evidence/`，教材只展示有助于理解的部分。

## 真实性与验收词汇

**真实执行**表示真实进程、真实数据库和真实请求。**注入**表示人为引入的故障，例如拦截浏览器保存请求并返回 503，或短暂停止本项目的 PostgreSQL 容器。**合成数据**表示为了控制变量生成的数据，例如十万条所有者时间线记录。**设计分析**表示尚未执行的部署方案。四者不能互相替代。

验收使用 VERIFIED、PARTIAL、BLOCKED、NOT_RUN。VERIFIED 只覆盖列出的条件和证据；PARTIAL 表示某些条件已验证但整体范围未闭合；BLOCKED 表示当前存在明确外部障碍；NOT_RUN 表示没有运行。一个配置文件存在，不代表它已成功部署；本机数据库恢复，不代表具备跨区域灾难恢复能力。

当前后端结果为 {{claim:backend_passed}} / {{claim:backend_total}} 项通过；浏览器结果为 {{claim:browser_passed}} 项通过。这些数字来自最终结构化证据，而不是手动填写的成绩表。历史失败结果也保留在仓库中，用来说明缺陷怎样被测试发现及修正。阅读时应同时注意实验日期、运行环境和证据文件是否来自同一次验收。

## 出版与工程的边界

教材采用 Markdown → Pandoc HTML → Mermaid → Playwright PDF 的本地流水线，目录页码由 PDF 书签映射后再次打印。版面程序检查越界、空白与极小文字；人工视觉检查负责识别图意、断页和信息密度。自动检查不能证明每一句自然语言都正确，也不能替代独立读者的教学反馈。

本项目由同一执行者完成实现、实验和这份独立成册的验收材料。没有把自测描述成第三方审计。Azure 只给出迁移与部署设计，不创建付费资源。所有人物与事件均为虚构；教学评估分数仅对应固定案件规则，不评价现实中的司法判断。

## 环境和复现入口

从仓库根目录执行下列步骤。先确认 Podman 机器或 Docker 引擎已运行；数据库脚本只操作 `echocase-postgres`，不会清理其他项目。数据库卷保留调查档案，停止容器不会删除数据。

```powershell
./scripts/dev-db.ps1
dotnet restore --locked-mode
./scripts/dev.ps1 migrate
./scripts/dev.ps1 api
# 在第二个终端
cd frontend
npm ci
npm run dev
```

第一次打开工作台需创建自己的本地账户。实验账户与合成案件用于学习，不包含真实案件资料。完整的测试、实验、容器运行、出版和清理命令见仓库 README 与 `docs/`。学习完成后保留你关心的证据，再按文档停用本项目进程。
