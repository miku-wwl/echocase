## 技术和教学复读

第 2、4、5、6、12 章实质重写；第 19 章用 16 处实际跨层摘录贯通稳定关联身份、命令、处理器、协调、事务、映射迁移、API、生成客户端、编辑器与验证。其余章节按固定实现逐章复核，保留已成立的领域、EF、MVCC、草稿与查询计划深度。

第二轮编辑检查从读者需要判断的问题出发，而非从测试通过与否出发：编译依赖与运行调用分别画；Logging 预处理与内侧行为分别解释；领域回调明确处于 Store 已开启事务中；跟踪器接受快照与显式提交分开；PostgreSQL 快照与应用 Version 分开；NSwag 构建生成与浏览器运行分开；草稿基线、冻结意图、缓存版本与 SQL 原值逐层连接。源码后解释行的作用、反例和限制，历史 SQL、HTTP、计划与界面均解释其含义。

回执前资源检查限定于已有调查的修改；创建调查没有目标加载分支。普通 Authorization 不替代 owner 过滤。慢写诊断的原失败路径标为源码推演，当前回归才是实际执行。成功 JSON 的完整形状没有运行时 schema 验证，空正文可能是 null；教材未夸大生成 DTO 的保证。

正文没有环境命令、原始 JSON、完整测试清单、CI 历史或代理活动记录。详细来源清单、图分类和出版命令单独存放。第二轮教学复读由同一执行代理完成；没有进行独立外部读者试读，不将其冒称为人工用户研究。
