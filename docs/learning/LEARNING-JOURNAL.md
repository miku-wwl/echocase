# 工程学习记录

| 实际发现 | 原因 | 修正与证据 |
|---|---|---|
| EF 工具未生成初始迁移 | 启动项目缺 Design 包 | 添加工具依赖，保留首次失败 TRX，再跑真实数据库 |
| 新关联被当作更新 | 手动 Guid 与默认主键生成约定冲突 | ValueGeneratedNever，完整调查测试恢复 |
| 并发竞争返回503 | 审计唯一约束可能先于根 UPDATE 失败 | 仅特定约束冲突映射412，验证一胜一拒绝 |
| 登录成功仍在登录页 | 清空 QueryCache 使现有 me 观察器失联 | 保留 me 查询并更新，浏览器重跑 |
| 版本号合同变成 number|string | JSON 允许数字字符串 | 严格数字策略，再生成合同与构建 |
| 停库后业务500 | EF 将 Npgsql 连接异常包装 | 匹配已知包装，重新真实断库验证503与恢复 |
| 容器网络假设不成立 | 开发库默认 pasta 不能接桥接网络 | 独立桥接网络与独立数据库验证重建 |
| QA 坏副本还缺前端源码 | 夹具未复制被引用片段 | 先校验正常副本，再注入单一故障并核对具体诊断 |

这些记录解释具体失效模式，不是生产事故经历。来源保留在 evidence/ 与实验目录。教材不把尚未执行的优化或云部署写成已完成事实。
